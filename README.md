# slipwatch-site

The website at [slipwatch.app](https://slipwatch.app): the front page and the help pages for
Slipwatch, a Jira Cloud app that shows who moved which due dates, by how many days, and why.

Built with [Starlight](https://starlight.astro.build).

| Command           | What it does                                 |
| :---------------- | :------------------------------------------- |
| `npm install`     | Installs what the site needs                 |
| `npm run dev`     | Starts a preview at `localhost:4321`         |
| `npm run build`   | Builds the public site into `./dist/`        |
| `npm run preview` | Shows the built public site on this computer |
